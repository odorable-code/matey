### 1. 프로젝트명

**Matey (메이티) - AI 융합 대화형 감정 동반 서비스**

---

### 2. 프로젝트 목표

### 핵심 목표

> “혼자가 아니야, Matey가 있으니까”
> 

Matey는 사용자의 고민을 단순히 해결해주는 AI가 아니라,

**친구처럼 감정을 이해하고 함께 대화하며 장기적인 감정 여정을 함께하는 AI 동반자 서비스**를 목표로 한다.

### 세부 목표

1. **감정 교류 중심의 대화 경험 제공**
    - 일방적 조언보다 공감과 대화 중심의 경험 제공
    - 사용자의 감정 흐름을 이해하고 자연스럽게 반응하는 AI 구현
2. **친구 같은 따뜻한 AI 서비스 제공**
    - 딱딱한 상담 도구가 아닌 편안한 대화형 AI 지향
    - 사용자가 스스로 맞는 말투와 분위기의 봇을 선택할 수 있도록 구성
3. **장기 사용을 유도하는 관계형 서비스 구축**
    - 감정 분석, 친밀도, 먹이주기, 모션 해금 등으로 지속 사용 유도
    - 단순 기능 소비가 아니라 “관계 형성” 중심의 서비스 경험 제공
4. **위험 감정 조기 파악 및 대응 기반 마련**
    - 감정 분석과 심리 위험도 1~5 분류를 통해 사용자 상태를 조기에 파악
    - 위험도에 따른 대응 방식과 안내 구조 마련
5. **봇과 사용자 간 상호작용 강화**
    - 봇 쪽지, 먹이주기, 친밀도, 해금 시스템 등 상호작용 요소 강화
    - 사용자가 자신의 봇과 정서적 연결감을 느낄 수 있도록 설계

---

### 3. 주요 기능

### 1) 메인 페이지

- 서비스 소개 및 핵심 가치 전달
- 로그인 / 회원가입
- 무료 체험 진입
- 주요 기능 안내
- FAQ 및 도움말 제공

### 2) 사용자 계정 및 인증

- 이메일 회원가입 / 로그인
- 소셜 로그인 (Naver, Kakao)
- 반자동 로그인
- 동일 이메일 사용 시 기존 계정 로그인 유도
- 비밀번호 재설정 및 계정 관리

### 3) 채팅 기능

- 멀티턴 대화
- 팝업형 채팅 UI
- 대화 흐름 문맥 유지
- 메시지 좋아요 / 싫어요 평가
- 채팅방 목록 관리
- 3시간 미작동 시 채팅방 아카이브
- 대화 요약 기능
- 만족도 팝업 제공

### 4) 감정 분석 및 위험도 분석

- 감정 분석 결과 저장 및 조회
- 대표 감정 및 변화 흐름 제공
- 심리 위험도 1~5 분류
- 고위험 사용자 대응 기준 마련

### 5) 봇 선택 및 상호작용

- 샘플 대화문구 기반 봇 선택
- 말투, 분위기, 공감 스타일 비교
- 봇 인기 랭킹 제공
- 월간 / 연간 인기 집계
- 좋아요 / 싫어요 기반 인기 산정

### 6) 친밀도 및 보상 시스템

- 일일 출석 체크
- 만능사료 지급
- 먹이주기 기능
- 친밀도 상승
- 친밀도에 따른 모션 해금
- 친밀도에 따른 채팅 배경 해금

### 7) 봇 모션 및 상태 표현

- 공통 봇 상태 애니메이션 제공
- 종별 개별 모션 제공
- 채팅 상황과 상호작용에 따라 상태 변화 표현

### 8) 쪽지 및 이벤트 기능

- 오랜만에 접속 시 봇 쪽지 제공
- 자정 접속 시 응원 메시지 제공
- 위험도 3 이상일 때 위로 및 행동 추천
- 감정 개선 시 축하 쪽지 제공

### 9) 마이페이지 / 대시보드

- 상담 기록 조회
- 감정 리포트 조회
- 친밀도 및 해금 요소 확인
- 보유 사료 확인
- 설정 및 알림 관리

### 10) 관리자 기능

- 사용자 기간 정지(정지/해제) 관리
- 감정/위험도 통계 조회
- 봇 인기 현황 조회
- 피드백 및 만족도 관리
- 문의/신고 답변 관리
- 공지사항 / FAQ 관리

### 11) 커뮤니티 운영

- 고민글(게시글) 작성 및 목록/상세 조회
- 댓글(답변) 작성 (사람이 직접 답변)
- 신고/문의는 사용자가 작성 → 관리자 답변
- QNA/FAQ는 사용자가 직접 작성할 수 없고, 관리자가 관리

### 4. 차별점

### 차별점 1. 친구 같은 AI 대화 경험

- 전문가형 상담 앱보다 심리적 진입장벽이 낮음
- 샘플 대화문구를 보고 사용자가 직접 맞는 스타일의 봇을 선택 가능

### 차별점 2. 감정 분석 + 위험도 분석 결합

- 단순 감정 분류에 그치지 않고 위험도 1~5 체계를 통해 상태 파악 가능
- 장기적인 감정 흐름과 위험 대응 방향까지 고려 가능

### 차별점 3. 관계형 상호작용 중심 설계

- 출석, 사료, 먹이주기, 친밀도, 모션 해금으로 관계 형성 유도
- 단순 챗봇이 아니라 “함께하는 동반자” 느낌 강화

### 차별점 4. 감정 변화에 반응하는 이벤트

- 쪽지, 응원, 선물, 축하 이벤트 등을 통해 사용자 경험 강화
- 정서적 연결감과 지속 사용 동기 제공

---

### 5. 삭제 및 변경된 방향

- 성인인증 기능 제거
- 식물 키우기 기능 제거
- 성향 테스트형 추천 방식 제거
- 봇 추천 방식을 샘플 대화 선택형으로 변경
- 채팅창 UI를 팝업형으로 변경
- 게이미피케이션 방향을 친밀도/먹이주기/해금 구조로 변경

---

### 6. 기대 효과

- 사용자가 감정적으로 덜 부담스럽게 AI 서비스를 사용할 수 있음
- 반복 사용을 통해 감정 흐름과 관계형 경험이 축적됨
- 친구 같은 AI와의 상호작용으로 서비스 체류 시간이 증가할 것으로 기대됨
- 감정 분석 및 위험도 분류 기반으로 사용자 상태를 체계적으로 관리할 수 있음
